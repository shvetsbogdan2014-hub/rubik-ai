1. Выберите сторону

Сканируйте стороны в порядке U, R, F, D, L, B. Центры задают цвет каждой стороны.

Фото должно показывать одну сторону почти прямо, целиком, без бликов. После распознавания проверьте все 9 клеток.

2. Исправить цвет клетки

Нажмите клетку, затем выберите правильный цвет.

О проекте

Текущая версия распознаёт цвет по центральным пикселям изображения и позволяет исправлять ошибки. Это локальный прототип компьютерного зрения, а не обученная нейросеть. Полноценный Kociemba solver и обученная модель пока не включены.

Данные хранятся в локальном хранилище браузера. Внешние API не вызываются.
